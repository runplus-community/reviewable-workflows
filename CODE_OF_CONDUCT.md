# Code of Conduct

Reviewable Workflow Handoffs is an open spec effort. Good discussion is direct, technical, and respectful.

## Expected Behavior

Participants should:

- discuss ideas, tradeoffs, and evidence rather than attacking people
- keep feedback specific and actionable
- assume draft specs and reference tools can be improved
- respect different experience levels, ecosystems, and operating environments
- avoid harassment, threats, insults, or repeated disruptive behavior

## Scope

This code of conduct applies to project spaces controlled by `runplus-community`, including issues, pull requests, discussions, documentation review, and related project communication.

## Enforcement

Maintainers may remove comments, close discussions, restrict participation, or take other reasonable moderation steps when behavior makes review and collaboration harder.

For security-sensitive reports, use the process in [SECURITY.md](SECURITY.md).

For conduct concerns, contact the maintainers privately through an available project-maintainer channel. Do not publish private personal information in public issues or discussions.

## Project Tone

The project welcomes skeptical review. Challenging the naming, threat model, examples, and claims is allowed and useful when done with technical clarity and respect.
