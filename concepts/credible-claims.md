# Credible Claims

Use clear claims that match the actual project scope.

## Good Claims

- Makes workflow handoffs easier to inspect before use.
- Keeps handoff behavior visible and version-controlled.
- Helps reviewers see what files are bundled or what commands are run.
- Reduces hidden workflow behavior.
- Provides language-specific reference implementations for Go and Rust.
- Complements supply-chain security practices by improving pre-execution and pre-consumption visibility.

## Avoid Claims

Do not say:

- Makes supply-chain attacks impossible.
- Supersedes SLSA.
- Supersedes OpenSSF Scorecard.
- Makes CI security unnecessary.
- Promises safe execution.
- Promises safe source transfer.
- Makes dependency scanning, signing, SBOMs, provenance, or code review unnecessary.

## Preferred Positioning

Short public line:

> Reviewable Workflows makes developer workflow handoffs visible before they run or before another project consumes them.

Category:

> Reviewable Workflow Handoffs

Primary slogan:

> Do not execute what you cannot review.

Source handoff slogan:

> Do not bundle what you cannot inspect.
