# Case Studies

Case studies connect Reviewable Workflow Handoffs to real incidents and ecosystem patterns.

They do not argue that a reviewable-handoffs spec would have stopped an incident. They are used to identify hidden handoffs, review surfaces, and practical spec requirements.

## Available Case Studies

- [Axios 2026 npm Compromise](axios-2026-npm-compromise.md)
- [Self-Critique: Axios 2026 as a Reviewable Workflow Handoffs Case Study](axios-2026-self-critique.md)

## Review Standard

Each case study should separate:

- what happened
- which handoffs were hidden or hard to inspect
- what Reviewable Workflow Handoffs could have made visible
- what it would not have stopped
- safe claims
- claims to avoid
- spec implications
