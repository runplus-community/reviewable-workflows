# Principles

Reviewable Workflow Handoffs is built around a small set of reviewability principles.

These principles are intentionally narrower than a security framework. They define what this spec effort asks tools and workflows to make visible before trust is required.

- [Do Not Execute What You Cannot Review](do-not-execute-what-you-cannot-review.md)
- [Do Not Bundle What You Cannot Inspect](do-not-bundle-what-you-cannot-inspect.md)
- [Prefer Language-Native Handoffs](prefer-language-native-handoffs.md)

Specs should turn these principles into concrete expectations for each ecosystem and handoff type.
